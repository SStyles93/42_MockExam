Assignment name  : n_queens
Expected files   : *.c, *.h
Allowed functions: atoi, fprintf, write, calloc, malloc, free, realloc, stdout, stderr
--------------------------------------------------------------------------------

Write a program that takes a number n and displays every solution to the
n queens problem: placing n queens on an n x n chessboard so that no two queens
attack each other (same row, same column or same diagonal).

Each solution is displayed on its own line as n numbers separated by spaces:
the k-th number is the row (from 0) of the queen in column k.

The order of the solutions does not matter. Negative values will not be
tested.

Examples:

$> ./n_queens 1 | cat -e
0$
$> ./n_queens 3 | cat -e
$> ./n_queens 4 | cat -e
1 3 0 2$
2 0 3 1$
$> ./n_queens 6 | wc -l
4
