Assignment name  : rev_print
Expected files   : rev_print.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes a string and displays it backwards, followed by a
newline.

If the number of arguments is not 1, display only a newline.

Examples:

$> ./rev_print "stressed" | cat -e
desserts$
$> ./rev_print "abc 123" | cat -e
321 cba$
$> ./rev_print | cat -e
$
