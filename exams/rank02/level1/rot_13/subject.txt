Assignment name  : rot_13
Expected files   : rot_13.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes a string and displays it with every letter replaced
by the letter 13 positions further in the alphabet, wrapping around after 'z'
('z' becomes 'm' and 'Z' becomes 'M'). Case is kept; other characters
are unchanged. The output is followed by a newline.

If the number of arguments is not 1, display only a newline.

Examples:

$> ./rot_13 "Hello, World!" | cat -e
Uryyb, Jbeyq!$
$> ./rot_13 "abc xyz" | cat -e
nop klm$
$> ./rot_13 | cat -e
$
