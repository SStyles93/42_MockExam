Assignment name  : ft_split
Expected files   : ft_split.c
Allowed functions: malloc
--------------------------------------------------------------------------------

Write a function that splits a string into words and returns them in a
NULL-terminated array of strings (the array and each word are allocated with
malloc).

A word is a sequence of characters delimited by spaces, tabs, newlines, or the
beginning or end of the string.

Your function must be declared as follows:

char	**ft_split(char *str);
