Assignment name  : print_hex
Expected files   : print_hex.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes a positive (or zero) number written in base 10 and
displays it in base 16, with lowercase letters, followed by a newline.

If the number of arguments is not 1, display only a newline.

Examples:

$> ./print_hex "42" | cat -e
2a$
$> ./print_hex "4096" | cat -e
1000$
$> ./print_hex "0" | cat -e
0$
$> ./print_hex | cat -e
$
