Assignment name  : ft_rrange
Expected files   : ft_rrange.c
Allowed functions: malloc
--------------------------------------------------------------------------------

Write a function that allocates (with malloc) an array of integers and fills it
with consecutive values from end to start, both included, then returns a
pointer to the first value.

Your function must be declared as follows:

int	*ft_rrange(int start, int end);

Examples:
- (1, 3)  gives  3, 2, 1
- (-1, 2) gives  2, 1, 0, -1
- (0, 0)  gives  0
- (0, -3) gives  -3, -2, -1, 0
