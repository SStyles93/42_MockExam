Assignment name  : ft_range
Expected files   : ft_range.c
Allowed functions: malloc
--------------------------------------------------------------------------------

Write a function that allocates (with malloc) an array of integers and fills it
with consecutive values from start to end, both included, then returns a
pointer to the first value.

Your function must be declared as follows:

int	*ft_range(int start, int end);

Examples:
- (1, 3)  gives  1, 2, 3
- (-1, 2) gives  -1, 0, 1, 2
- (0, 0)  gives  0
- (0, -3) gives  0, -1, -2, -3
