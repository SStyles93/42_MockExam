Assignment name  : wdmatch
Expected files   : wdmatch.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes two strings and checks whether the first one can be
written using characters of the second one, in the same order (each character
of the second string can be used at most once).

If it is possible, display the first string followed by a newline; otherwise
display only a newline.

If the number of arguments is not 2, display only a newline.

Examples:

$> ./wdmatch "cat" "a cool hat with a tail" | cat -e
cat$
$> ./wdmatch "cat" "tac" | cat -e
$
$> ./wdmatch "aa" "banana" | cat -e
aa$
$> ./wdmatch "cat" | cat -e
$
