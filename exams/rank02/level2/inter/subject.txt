Assignment name  : inter
Expected files   : inter.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes two strings and displays, without duplicates, the
characters that appear in both strings, in the order in which they appear in
the first one. The output is followed by a newline.

If the number of arguments is not 2, display only a newline.

Examples:

$> ./inter "mississippi" "pins" | cat -e
isp$
$> ./inter "hello world" "lower" | cat -e
lowr$
$> ./inter "abc" "xyz" | cat -e
$
$> ./inter "abc" | cat -e
$
