Assignment name  : union
Expected files   : union.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes two strings and displays, without duplicates, the
characters that appear in either of them, in the order in which they appear on
the command line (first string, then second). The output is followed by a
newline.

If the number of arguments is not 2, display only a newline.

Examples:

$> ./union "banana" "apple" | cat -e
banple$
$> ./union "abc" "cba" | cat -e
abc$
$> ./union "" "zz top" | cat -e
z top$
$> ./union "abc" | cat -e
$
